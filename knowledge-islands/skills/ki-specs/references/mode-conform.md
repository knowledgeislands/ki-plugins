# Mode CONFORM — bring Specifications into line

**Precondition:** run [AUDIT](mode-audit.md) first and retain its findings.

1. Run `ki repo conform --skill ki-specs`. The hosted action normalises only mechanically recognisable near-miss headings; the host owns dry-run, publication, rollback, and post-conform audit.
2. Repair other mechanical findings in place: register files and prefixes, add missing normative keywords, declare truthful conformance, and add concrete `_Verify:_` plans.
3. Do not fabricate conformance or evidence. A conforming claim without current proof becomes pending or divergent; an accepted unfinished requirement remains numbered.
4. Keep only unaccepted candidates in Gaps. Do not promote a candidate without product authority.
5. Re-run AUDIT and report remaining judgment work.
